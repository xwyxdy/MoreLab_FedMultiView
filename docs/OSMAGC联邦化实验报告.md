# OSMAGC 联邦化实验报告

## 一、视图间唯一耦合

OSMAGC 主循环五步 `A → R → Z → H → α` 里，`A_v / R_v / Z_v / α_v` 全部**逐视图独立**，
唯一跨视图的一步是 `H` 的更新：

```
H ← solve( (λI + γD), λ · Σ_v R_v Z_v )
```

视图之间只通过一个**求和项 `Σ_v R_v Z_v`** 发生耦合。

| 步骤 | 需要的数据 | 是否跨视图 |
|---|---|---|
| `A_v` | `X_v, Z_v` | 否 |
| `R_v` | `Z_v, H` | 否 |
| `Z_v` | `X_v, A_v, R_v, H, α_v` | 否 |
| `H` | **`Σ_v R_v Z_v`** | **是（唯一）** |
| `α_v` | 本视图残差标量 | 否 |

## 二、改动

只把那个求和项从内存搬到网络，其余计算原样保留：

- **客户端 v**（持有视图 v 原始数据 `X_v`，数据不出门）：
  本地算 `A_v / R_v / Z_v`，上传 `S_v = R_v Z_v`（`dim×N`）和一个标量残差 `e_v`。
- **服务器**（持有 `H`、`α`，以及公开栅格几何 `D`）：
  聚合 `Σ_v S_v` → `H ← solve(λ·Σ_v S_v)`，`α_v ← e_v / Σ e_v`，下发 `H`、`α_v`。

因为 `Σ_v S_v` 是精确求和、各视图 `A/R/Z` 更新逐位独立，且求和顺序与集中式一致
（`v=0..V-1`），所以联邦版与集中版的 `H` 序列**逐元素相同**。

**更新公式一行未改，数值代码零改动**，只是把求和从内存搬到了网络。

## 三、结果

| 数据集 | 方式 | ACC | NMI | ARI | Purity | 通信量 |
|---|---|---|---|---|---|---|
| Trento | 集中式 | 0.9158 | 0.8584 | 0.9147 | 0.9158 | — |
| | 联邦式（2 客户端） | 0.9158 | 0.8584 | 0.9147 | 0.9158 | 191 MB |
| Augsburg | 集中式 | 0.5021 | 0.4250 | 0.3132 | 0.7022 | — |
| | 联邦式（3 客户端） | 0.5021 | 0.4250 | 0.3132 | 0.7022 | 541 MB |
| Berlin | 集中式 | 0.4102 | 0.2298 | 0.1524 | 0.6461 | — |
| | 联邦式（2 客户端） | 0.4102 | 0.2298 | 0.1524 | 0.6461 | 2.10 GB |

三个数据集上联邦版与集中版四个指标**四位小数完全一致**。

无损性（H 序列逐元素对比）：Trento / Augsburg 各 10 轮 `max|ΔH| = 0.00e+00`，
标签完全一致。

**结论：精度损失 = 0，代价全在通信量（与像素数 N 成正比，191 MB → 2.10 GB）。**

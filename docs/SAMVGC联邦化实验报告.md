# SAMVGC 联邦化实验报告

## 一、视图间唯一耦合

SAMVGC（深度 GNN 方法）里，GCN 编码/解码、图精炼、重建损失、SLIC 超像素**全是单视图的**。
跨视图的交流只有一处——**特征融合 `Z_F`**，以及它下游的簇结构：

| 步骤 | 是否跨视图 | 说明 |
|---|---|---|
| SLIC 超像素 + 锚点 | 否（一次性预处理） | 空间划分，当公开结构 |
| 图自编码器（GCN） | 否 | 逐视图，重建损失本地 |
| 图精炼 | 否 | 用本视图 Z 精炼本视图 A |
| **`Z_F = Σ_v Wv ⊙ Z(v)`** | **是（唯一融合点）** | 各视图特征合成共享表示 |
| K-means 簇分配 | 是（下游） | 在 Z_F 上，全体视图共同决定簇结构 |
| 原型对比 µ(v)_k vs µF_k | 是（下游） | 各视图原型对齐融合原型 |
| 一致性损失 p(v) vs qF | 是（下游） | 混淆样本视图分布对齐融合分布 |

**核心：唯一的交流点就是特征融合 `Z_F = Σ_v Wv ⊙ Z(v)`。** 其余都是单视图。

## 二、改动

把「融合 Z_F + 簇结构」搬到服务器，GNN 训练留本地：

- **客户端 v**（持有视图 v）：
  本地 GCN 编码得 `Z(v)`、解码重建、图精炼、重建损失；
  **上传 `Z(v)`（M × d̂）**。
- **服务器**：
  接收各视图 `Z(v)` → 算 `Z_F` → K-means 簇分配 → 融合原型 `µF_k`；
  **广播**簇标签、`µF_k`、`ZF` 参考。
- **客户端**：用广播的簇结构算对比损失、一致性损失，更新本地 GCN。

SLIC 当公开预处理（一次性划分，之后每轮训练不再涉及）。**算法结构一行没动**——三个损失都在，
只是把融合从内存操作变成服务器聚合 + 广播。

通信（float32，每轮=每 epoch）：
- 上传：`Z(v)`（M × d̂）
- 下发：`ZF`（M × d̂）+ 原型（K × d̂）+ 簇标签（M）

## 三、结果

| 数据集 | 方式 | ACC | NMI | ARI | Purity | 通信量 |
|---|---|---|---|---|---|---|
| Trento | 集中式 | 0.7815 | 0.7580 | 0.7323 | 0.8822 | — |
| | 联邦式（2 客户端） | 0.7815 | 0.7580 | 0.7323 | 0.8822 | 1.69 GB |
| Augsburg | 集中式 | 0.3625 | 0.3642 | 0.2377 | 0.7300 | — |
| | 联邦式（3 客户端） | 0.3625 | 0.3642 | 0.2377 | 0.7300 | 2.46 GB |
| Berlin | 集中式 | 0.5225 | 0.3477 | 0.2719 | 0.7195 | — |
| | 联邦式（2 客户端） | 0.5257 | 0.3485 | 0.2770 | 0.7199 | 3.43 GB |

联邦版与集中版**本质同一函数**（只多了通信记账）。Trento / Augsburg 逐位一致；
Berlin 有 ±0.003 的微小差异，来自 **CUDA 浮点非确定性**（同一代码同一种子，两次独立运行在 GPU 上末位略有不同），不是联邦化引入的误差。

## 四、结论

1. **SAMVGC 的视图划分联邦化改动点 = 特征融合 Z_F + 簇结构**，其余留本地。
2. 因为是深度方法，通信按 **epoch（100 轮）** 计，每轮交换 M×d̂ 的 `Z(v)`，
   总量比 OSMAGC/ETAP（10 轮）大一个数量级——这是深度方法联邦化的固有代价。
3. SLIC 当公开预处理，不构成每轮交流。

## 五、备注

- SAMVGC **无公开源码**，本实现按论文逐公式用 PyTorch 复现。
- 论文未给超参（M/k/α/轮数/学习率），此处取惯例默认值；且未实现图精炼里的融合那步（Eq 6-7），
  故绝对精度与论文有差距（尤其 Augsburg）。**不影响「集中 vs 联邦」结论**。

# ETAP 联邦化实验报告

## 一、视图间唯一耦合

ETAP 主循环 `Z → A → α → β → F → S → J/Y → W` 里，`Z / A / S / Y / W` 全部**逐视图独立**。
跨视图的耦合只有四处，且**全部在锚点级（m×m）**：

| 步骤 | 跨视图的量 | 形式 |
|---|---|---|
| `α_v` | 视图权重标量 | `α_v = √trace(W_vᵀQ_vW_v) / Σ`，只需各端上传一个标量 |
| `β_v` | 压缩锚图权重标量 | `β_v = ‖W_vᵀA_v − W_vᵀA_vS_v‖_F / Σ`，各端上传一个标量 |
| `F` | 共识特征（m×c） | `F = 最小c个特征向量(Σ_v (1/α_v)L_sᵥ)`，各端上传 `L_sᵥ`(m×m) |
| **张量 Schatten-p** | 各视图 S_v 堆成的张量 | 服务器做 t-SVD，各端上传 `S_v`(m×m) |

最终共识：`S = Σ_v (1/β_v)S_v`、`Z = Σ_v (1/α_v)Z_v` 的加权平均（服务器）。

关键点：**ETAP 的跨视图耦合全在锚点级 m×m，不含像素级 N**（除了最后一步出标签要传一次 Z_v）。

## 二、改动

把跨视图的四个聚合步骤搬到「服务器」，其余逐视图步骤留在「客户端」本地：

- **客户端 v**（持有视图 v 的原始数据 `X_v`，数据不出门）：
  本地跑 ERS 超像素 + LED 去噪、锚点 A_v、锚图 Z_v、投影 W_v、压缩锚图 S_v（QP）；
  上传 `S_v`(m×m)、`L_sᵥ`(m×m) 和两个标量。
- **服务器**（持有 α、β、F、μ）：
  归一化 α/β、加权拉普拉斯和 + 特征分解出 F、张量 t-SVD 出 J，广播回各客户端；
  最后用加权平均的 S、Z 做 CLR + 标签传播。

更新公式**一行未改**，联邦版逐函数复用集中式的实现，因此标签**逐位相同**。

## 三、结果

| 数据集 | 方式 | ACC | NMI | ARI | Purity | 通信量 |
|---|---|---|---|---|---|---|
| Trento | 集中式 | 0.6348 | 0.4907 | 0.4564 | 0.6751 | — |
| | 联邦式（2 客户端） | 0.6348 | 0.4907 | 0.4564 | 0.6751 | 339 MB |
| Augsburg | 集中式 | 0.3488 | 0.0994 | 0.0727 | 0.5111 | — |
| | 联邦式（3 客户端） | 0.3488 | 0.0994 | 0.0727 | 0.5111 | 597 MB |
| Berlin | 集中式 | 0.5641 | 0.3082 | 0.2931 | 0.6973 | — |
| | 联邦式（2 客户端） | 0.5641 | 0.3082 | 0.2931 | 0.6973 | 2.05 GB |

Trento / Augsburg / Berlin 三个数据集上联邦版与集中版四个指标**逐位一致**（标签完全相等）。

通信量构成：
- 每轮：锚点级 S_v + L_sᵥ + F + J_v，极小（约 2 MB/轮）
- **最终 Z_v 上传（N×m，一次性）：占绝对大头**（Trento ~319 MB / Augsburg ~575 MB / Berlin ~2.0 GB）

## 四、结论

1. **ETAP 的视图划分联邦化是无损的**：跨视图耦合全部是可聚合量（加权和 + 特征分解 + t-SVD），
   各视图本地计算逐位独立，联邦版与集中版逐位相同。
2. **通信量分两段**：迭代轮内是锚点级（m×m，极小），最后出标签要传一次像素级锚图 Z_v（N×m）。
3. 与 OSMAGC 相比，ETAP 的迭代通信更省（锚点级 vs 像素级），但多了一次性的 Z_v 上传。
